# Swaraj Mali — Portfolio

First-viewport clone adapted from [chanhdai.com](https://github.com/ncdai/chanhdai.com) (MIT).

## Scope

Only the landing first view:
- Site header (SM mark, nav, utilities)
- Profile header (isometric mark, avatar, name, flip lines)
- Social links dock

## Develop

```bash
npm install
npm run dev
```

## Notes

- Placeholders live in `src/data/site.ts`
- `_inspo-chanhdai/` is a local reference clone (gitignored)
- `.env` is for local/agent tooling only (OpenRouter) — not used by the app
- Isometric mark interaction/geometry credited to ncdai (MIT); header mark is SM
